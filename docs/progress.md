# История выполнения лабораторных работ

## ЛР 1 — Старт проекта на React и TypeScript

### Результат

Создан проект «Каталог игр» на React, TypeScript и Vite.
Начальный экран содержит название, описание и пустой раздел «Мои игры».
Добавлены собственные стили, русский язык страницы и название вкладки.
Удалены демонстрационные изображения.
Подготовлены README, .node-version и .gitignore.

### Порядок проверки

1. В папке frontend выполнить npm ci и npm run dev.
   Открыть адрес Local и проверить начальный экран.
2. Проверить отображение на узком экране:
   текст читается, горизонтальной прокрутки нет.
3. Временно заменить строковое значение appTitle на число.
   Выполнить npm run build: ожидается ошибка TypeScript TS2322.
4. Вернуть строковое название и сохранить файл.
   Повторить npm run build: сборка должна пройти.
5. Выполнить npm run preview.
   Открыть адрес Local и проверить готовую сборку.
6. После публикации клонировать репозиторий в новую папку.
   Выполнить npm ci, npm run build и npm run dev в frontend.

В PowerShell при необходимости используйте npm.cmd вместо npm.

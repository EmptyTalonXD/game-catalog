# История выполнения лабораторных работ

## ЛР 1 — Старт проекта на React и TypeScript

### Результат

Создан проект «Каталог игр» на React, TypeScript и Vite.
Начальный экран содержит название, описание и пустой раздел «Мои игры».
Добавлены собственные стили, русский язык страницы и название вкладки.
Удалены демонстрационные изображения.
Подготовлены README, .node-version и .gitignore.

### Порядок проверки

1. В папке frontend выполнить npm ci и npm run dev.
   Открыть адрес Local и проверить начальный экран.
2. Проверить отображение на узком экране:
   текст читается, горизонтальной прокрутки нет.
3. Временно заменить строковое значение appTitle на число.
   Выполнить npm run build: ожидается ошибка TypeScript TS2322.
4. Вернуть строковое название и сохранить файл.
   Повторить npm run build: сборка должна пройти.
5. Выполнить npm run preview.
   Открыть адрес Local и проверить готовую сборку.
6. После публикации клонировать репозиторий в новую папку.
   Выполнить npm ci, npm run build и npm run dev в frontend.

В PowerShell при необходимости используйте npm.cmd вместо npm.

### Выполненные проверки

- Приложение запущено в режиме разработки.
- Ошибка типов TS2322 получена при присваивании числа вместо строки.
- После исправления сборка прошла успешно.
- Готовая сборка открыта через preview.

- Проверено отображение при ширине 375 пикселей:
  текст читается, карточка помещается в экран.
- После добавления собственной иконки вкладки
  ошибка загрузки favicon исчезла; ошибок в консоли не обнаружено.
- Копия первого коммита d9721e1 скачана с GitHub:
  npm ci, сборка и запуск выполнены успешно.

После добавления иконки сборка выполнена успешно,
каталог и иконка проверены через preview.
Версия 36778f7 получена с GitHub в отдельную проверочную копию.

## ЛР 2 — Страницы приложения и навигация

### Результат

- Продолжен проект «Каталог игр» из ЛР 1.
- Описаны типы Game и GameStatus.
- Добавлены пять демонстрационных записей.
- Создан компонент GameCard с типизированными props.
- Список выводит карточки через map со стабильным key.
- Добавлены страницы списка, подробностей,
  заглушки создания и неизвестного адреса.
- Подробности игры определяются по id из URL.
- Создан общий AppLayout с навигацией и Outlet.
- Подключён React Router.
- Добавлены адаптивные стили и видимый фокус клавиатуры.
- Обновлён README.

### Порядок проверки

1. Из frontend выполнить npm ci и npm run dev.
   Открыть адрес Local: корневой путь / ведёт на /games.
2. Проверить список из пяти игр и открыть две разные карточки.
   На странице подробностей должны отображаться все поля записи.
3. Открыть /games/g2 в новой вкладке и обновить страницу.
   Должна остаться карточка Satisfactory.
4. Открыть /games/new:
   видна заглушка формы и общая навигация.
5. Открыть /unknown:
   отображается «Страница не найдена».
6. Открыть /games/missing:
   отображается «Игра не найдена».
7. Временно передать пустой массив:
   отображается «Игр пока нет».
   После проверки восстановить пять записей.
8. Проверить ширину 360 пикселей, фокус через Tab,
   открытие ссылки через Enter и историю назад/вперёд.
9. Во вкладке «Сеть» очистить запросы и перейти
   между экранами по внутренним ссылкам.
   Новые HTML-документы загружаться не должны.
10. Выполнить npm run build и npm run preview.
    Напрямую открыть /games/g3 и обновить страницу.
    Проверить консоль: нет ошибок приложения
    и предупреждений о key.

В PowerShell при необходимости использовать npm.cmd вместо npm.

### Выполненные проверки

- Список, подробности и заглушка создания открываются.
- Прямое открытие и обновление карточки работают.
- Неизвестный путь и отсутствующая игра
  обрабатываются разными сообщениями.
- Проверен пустой список; исходные записи восстановлены.
- Проверены узкий экран и управление клавиатурой.
- Внутренние переходы не загружают новый HTML-документ.
- Проверка типов и сборка выполнены успешно.
- Прямое открытие карточки проверено в preview.
- По результатам просмотра консоли ошибок приложения
  и предупреждений о key не обнаружено.

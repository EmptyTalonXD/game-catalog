# Каталог игр

Учебный проект по дисциплине «Лабораторный практикум».

Днестрян Максим Сергеевич  
Группа: ФТ24ДРб2ИВ

## Тема и основной сценарий

Приложение помогает игроку вести личную коллекцию игр.
Пользователь добавляет игры, указывает платформу и жанр,
меняет статус прохождения, выставляет оценку и оставляет заметки.

## Технологии

React, TypeScript, React Router, Vite, CSS.

Версия Node.js: 24.21.0.
Для запуска также необходим npm.

## Запуск

Откройте терминал в корне проекта и выполните:

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

Откройте адрес Local, который появится в терминале.
Для остановки сервера нажмите Ctrl+C.

## Сборка и просмотр

Из папки frontend выполните:

```powershell
npm.cmd run build
npm.cmd run preview
```

Команда build проверяет типы TypeScript и создаёт сборку в frontend/dist.
Команда preview запускает локальный просмотр готовой сборки.
Откройте адрес Local из терминала.

## Текущие ограничения

Добавление, редактирование и удаление игр пока не реализованы.
Страница добавления содержит заглушку;
форма появится в ЛР 3.

Фильтры, база данных, авторизация и серверная статистика
будут добавлены в следующих лабораторных работах.

## Адреса страниц

- / — перенаправление на /games.
- /games — список игр.
- /games/g1 — пример подробностей игры Minecraft.
- /games/new — заглушка добавления игры.
- /unknown — пример неизвестной страницы.
- /games/missing — пример отсутствующей игры.

Адреса указываются после адреса сервера,
напечатанного в терминале.

## Данные

Записи находятся в типизированном массиве src/data/games.ts
внутри frontend.

Используются реальные названия игр и вручную заданные
демонстрационные данные о статусах и достижениях.
Данные не загружаются из Steam или других внешних сервисов.

Процент достижений хранится отдельно от статуса прохождения
и не означает процент завершения сюжета.

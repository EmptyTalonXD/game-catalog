# Каталог игр

Учебный проект по дисциплине «Лабораторный практикум».

Днестрян Максим Сергеевич

## Тема и основной сценарий

Приложение помогает игроку вести личную коллекцию игр.
Пользователь добавляет игры, указывает платформу и жанр,
меняет статус прохождения, выставляет оценку и оставляет заметки.

## Технологии

React, TypeScript, React Router, Vite, CSS.

Версия Node.js: 24.21.0.
Для запуска также необходим npm.

## Запуск

Откройте терминал в корне проекта и выполните:

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

Откройте адрес Local, который появится в терминале.
Для остановки сервера нажмите Ctrl+C.

## Сборка и просмотр

Из папки frontend выполните:

```powershell
npm.cmd run build
npm.cmd run preview
```

Команда build проверяет типы TypeScript и создаёт сборку в frontend/dist.
Команда preview запускает локальный просмотр готовой сборки.
Откройте адрес Local из терминала.

## Текущие ограничения

Игры хранятся только в памяти открытого приложения.
Внутренние переходы сохраняют изменения.
После обновления страницы восстанавливаются исходные пять игр.

Новые записи после обновления исчезают,
поэтому их прежние адреса показывают «Игра не найдена».

База данных, авторизация, серверная статистика
и подключение внешних игровых сервисов пока не реализованы.
Фильтр может сбрасываться при уходе со страницы списка.

## Адреса страниц

- / — перенаправление на /games.
- /games — список игр.
- /games/g1 — пример подробностей игры Minecraft.
- /games/new — форма добавления игры.
- /games/g1/edit — пример редактирования игры Minecraft.
- /unknown — пример неизвестной страницы.
- /games/missing — пример отсутствующей игры.

Адреса указываются после адреса сервера,
напечатанного в терминале.

## Данные

Записи находятся в типизированном массиве src/data/games.ts
внутри frontend.

Используются реальные названия игр и вручную заданные
демонстрационные данные о статусах и достижениях.
Данные не загружаются из Steam или других внешних сервисов.

Процент достижений хранится отдельно от статуса прохождения
и не означает процент завершения сюжета.

## Результат ЛР 3 — Формы и локальное состояние

- Общий список игр хранится в состоянии App.
- Реализованы создание, просмотр, редактирование и удаление игр.
- Для создания и редактирования используется одна форма GameForm.
- Форма хранит отдельный черновик:
  отмена не изменяет сохранённую запись.
- Новая игра получает UUID; при редактировании id сохраняется.
- Удаление выполняется после подтверждения.
- Добавлен фильтр по статусу и его сброс.
- Различаются пустая коллекция и отсутствие совпадений фильтра.
- В общей шапке показано предупреждение о временном хранении.

### Проверка ввода

- Название после удаления пробелов по краям:
  от 3 до 100 символов.
- Платформа и жанр обязательны.
- Оценка: от 1 до 10 либо не указана.
- Достижения: от 0 до 100 процентов либо не указаны.
- При ошибке форма сохраняет введённые значения.
- Пустые числовые поля сохраняются как null;
  нулевой процент достижений сохраняется как 0.

# Каталог игр

Учебный проект по дисциплине «Лабораторный практикум».

## Тема и основной сценарий

Приложение помогает игроку вести личную коллекцию игр.
Пользователь добавляет игры, указывает платформу и жанр,
меняет статус прохождения, выставляет оценку и оставляет заметки.

## Технологии

React, TypeScript, Vite, CSS.

Версия Node.js: 24.21.0.
Для запуска также необходим npm.

## Запуск

Откройте терминал в корне проекта и выполните:

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

Откройте адрес Local, который появится в терминале.
Для остановки сервера нажмите Ctrl+C.

## Сборка и просмотр

Из папки frontend выполните:

```powershell
npm.cmd run build
npm.cmd run preview
```

Команда build проверяет типы TypeScript и создаёт сборку в frontend/dist.
Команда preview запускает локальный просмотр готовой сборки.
Откройте адрес Local из терминала.
